## Global flags

Global flags are placed before the command:

```bash
spendly --json --non-interactive expenses list --limit 25
```

| Flag | Behavior |
| --- | --- |
| `--json` | Writes one versioned JSON document to standard output. |
| `--non-interactive` | Disables prompts and requires stable IDs for ambiguous domain selectors. |
| `--debug` | Writes redacted diagnostics to standard error. |
| `--no-color` | Disables terminal color. |
| `--no-retry` | Disables bounded retries for read-only requests. |
| `--allow-file-storage` | Allows the explicit owner-only credential-file fallback. |

## JSON output

A successful command returns one document shaped like:

```json
{
  "schemaVersion": 1,
  "data": {
    "example": "synthetic value"
  },
  "meta": {}
}
```

An error returns:

```json
{
  "schemaVersion": 1,
  "error": {
    "code": "INVALID_INPUT",
    "details": {},
    "message": "A required value is missing",
    "retryable": false
  }
}
```

Agents should parse the document instead of terminal text. Diagnostics remain
on standard error so they cannot corrupt JSON output.

## Exit codes

| Code | Meaning |
| ---: | --- |
| `0` | Success. |
| `1` | Unexpected internal failure. |
| `2` | Invalid command or input. |
| `3` | Authentication or account setup required. |
| `4` | Resource not found. |
| `5` | Revision, idempotency, state, or currency conflict. |
| `6` | Deletion confirmation required, invalid, or expired. |
| `7` | Temporary network or service failure. |

The JSON error code is more specific than the process exit code and should be
used for recovery decisions.

## Pagination

Expense and account-transaction lists use opaque cursors:

```bash
spendly --json expenses list --limit 25
spendly --json expenses list --limit 25 --cursor cursor_from_previous_page
```

Do not decode or invent a cursor. A page is not a complete total when
`nextCursor` is non-null.

## Dates and timezone

Dates use `YYYY-MM-DD`. When a date is omitted, Spendly resolves today in the
computer's detected IANA timezone and reports the resolved date and timezone.
If timezone detection fails, provide `--date` explicitly.

Date filters are inclusive:

```bash
spendly expenses list --from 2026-09-01 --to 2026-09-30
```

## Selectors

Humans may use exact names where help documents a name selector. Matching
trims surrounding whitespace and ignores case, but never uses fuzzy matching.
Ambiguity returns candidates and performs no write.

Agents using `--non-interactive` should first read the resource and then pass
its stable ID:

```bash
spendly --json --non-interactive accounts list
spendly --json --non-interactive expenses list --account-id account_demo_001
```

Always check installed help before using an unfamiliar option:

```bash
spendly accounts adjust-balance --help
```
