---
title: Transfers
description: Transfer funds safely between active accounts with atomic revision checks.
---

A transfer moves funds between two active accounts atomically. Both accounts
must resolve to the same currency, and the source and destination must be
different.

## Read both accounts

```bash
spendly accounts get account_demo_source
spendly accounts get account_demo_destination
```

Confirm the IDs, currencies, balances, active state, and current revisions.

## Preview the transfer

```bash
spendly accounts transfer \
  --amount 125.00 \
  --from-account-id account_demo_source \
  --to-account-id account_demo_destination \
  --date 2026-09-05 \
  --note "Move to savings" \
  --if-from-revision 7 \
  --if-to-revision 4 \
  --idempotency-key transfer-demo-001 \
  --dry-run
```

Review:

- Source and destination names and IDs.
- Currency and normalized amount.
- Both before and after balances.
- Both expected revisions.
- Transfer-out and transfer-in ledger effects.
- Any negative source-balance warning.

A negative source balance is a warning, not automatic rejection. Stop if it
does not match the user's intent.

## Commit once

Run the identical command without `--dry-run`:

```bash
spendly accounts transfer \
  --amount 125.00 \
  --from-account-id account_demo_source \
  --to-account-id account_demo_destination \
  --date 2026-09-05 \
  --note "Move to savings" \
  --if-from-revision 7 \
  --if-to-revision 4 \
  --idempotency-key transfer-demo-001
```

The backend updates both balances and appends both ledger entries in one
transaction. A stale revision, archived account, same-account transfer, or
currency mismatch performs no write.

Completed transfers cannot be edited or deleted in version 1. Correct an
incorrect transfer only through a new, explicitly authorized compensating
transfer.

## Uncertain result

Do not automatically retry. Read both accounts and their ledger history first.
If the result remains unknown, repeat the exact same intended transfer with the
same idempotency key. A new key could create a duplicate transfer.
