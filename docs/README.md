# Feature Specs (scratch space)

This folder is for **active, in-flight feature work only** — not long-lived documentation.

## How to use it

1. Create a spec under `docs/features/` when you start a feature, e.g. `docs/features/recurring-expenses.md`.
2. Keep it short: goal, scope, open questions, and a rough task list.
3. **Delete the file when the feature ships.** The code and tests are the source of truth.

## What not to put here

- Permanent API or route documentation (read the code instead)
- Project status checklists or roadmaps (use GitHub Issues)
- Duplicates of `schema.ts`, README, or AGENTS.md

## Template

Copy `docs/features/_template.md` when starting something new.
