# Spendly

Personal expense tracking with custom cycles, categories, accounts, tags, and
comparison views. Includes a Next.js web app, Convex backend, and local CLI.

## Product principles

- Track spending, not income.
- Use personal cycles rather than calendar months.
- Planning is optional; overspending is data, not an error.
- History is editable; comparisons are observational, not judgmental.

## Development

See [CONTRIBUTING.md](CONTRIBUTING.md) for prerequisites, environment setup,
commands, and contribution workflow.

```bash
pnpm install
pnpm dev:setup
# Configure environment files, then:
pnpm dev
```
